这是个让人难受的月份。

但至少完成了如下的事情。

1. 确定了后续居住的地点。
2. 向家里坦白失业。
3. 尝试了低成本的 token 计划。
4. 复健开车，尝试了从 天河智慧城 开到 龙岗大运。

而没有做的很好的。

1. 被京东金融骗了，以减低借款利率为理由，借出了 18 万，结果多付了快 500 利息，还浪费了一天的时间。
2. 租车从深圳出发开到广州，本以为能够比较灵活，结果被限行绊倒了，到了深圳之后还是打车为主。加上作息没调整好，限行结束之后光躺车里休息了。
3. 资费套利迁移消耗的时间太多了，需要进行更严肃的复盘。
4. 作息管理非常失败，熬大夜对作息 和 身体健康 的影响太大了。不仅导致白天、下午一直很困，影响工作；而且睡眠不足再次给心脏带来很大压力。

### 后续的计划 与 调整

> 凡事预则立，不预则废

计划很重要。
说是 打工思维 也好，还是 做题家思维 也好，以前更多时候都是倾向于用 蛮劲 和 死努力。
稍微好一点的点是会不断得优化工具，提高效率，但依旧方向上错误，Vibe Coding 甚至放大了这个错误度。

> 吾日三省吾身。

反思复盘 总结也很重要。
尤其是独立开发的时候，审视自己的工作情况，审视项目的情况。
尤其是在碰上困难的时候，能够跳出来看问题，避免空转和用死劲。

**由此为了增强 计划 和 复盘 的流程。预计将日常的任务调整。**

1. 对昨天任务的简单总结，对今天的进行计划。
2. 等到计划完毕之后，就按照计划推进。

大致上，白天进行计划和复盘，下午和晚上则是 计划的执行 和 休息以及学习。

#### 计划模式

基本上所有的 Harness 都提供了 计划模式。这是很好的抽象，人也需要。
这边需要提的时候进行一个注意力的分配，起因是我个人在平时 “工作“ 的时候，习惯听 小说 / 播客 / 视频。但边听边工作其实对工作是有影响了，尤其是当工作需要一些思考的时候。并且之前的经验表明，对任务的完成效率是有负面影响的。
这次将计划的时间划分出来的同时，也切出 计划模式 和 执行模式。

计划模式下一个特点是，只听音乐，不听 小说 / 播客 / 视频。分配更多的”智能“额度。

#### 休息与学习

反思之前的 Gap 时期，我发现最缺失的就是 休息 和 学习。

休息很需要，清爽的脑子才能方便接收宇宙信号，解开一些难解的纠结。
不管是出去走走，还是看看名著，看看电影动画，都可以。

学习更是需要，尤其是现在 AI 的发展，使得这件事情变得非常舒服，比起以前抱着书啃，搭配 AI 是真的能够将 自学 这件事情给通关。
