这是个让人难受的月份。

但至少完成了如下的事情。

1. 确定了后续居住的地点。
2. 向家里坦白失业。
3. 尝试了低成本的 token 计划。
4. 复健开车，尝试了从 天河智慧城 开到 龙岗大运。

而没有做的很好的。

1. 被京东金融骗了，以减低借款利率为理由，借出了 18 万，结果多付了快 500 利息，还浪费了一天的时间。
2. 租车从深圳出发开到广州，本以为能够比较灵活，结果被限行绊倒了，到了深圳之后还是打车为主。加上作息没调整好，限行结束之后光躺车里休息了。
3. 资费套利迁移消耗的时间太多了，需要进行更严肃的复盘。
4. 作息管理非常失败，熬大夜对作息 和 身体健康 的影响太大了。不仅导致白天、下午一直很困，影响工作；而且睡眠不足再次给心脏带来很大压力。

### 后续的计划 与 调整

> 凡事预则立，不预则废

计划很重要。
说是 打工思维 也好，还是 做题家思维 也好，以前更多时候都是倾向于用 蛮劲 和 死努力。
稍微好一点的点是会不断得优化工具，提高效率，但依旧方向上错误，Vibe Coding 甚至放大了这个错误度。

> 吾日三省吾身。

反思复盘 总结也很重要。
尤其是独立开发的时候，审视自己的工作情况，审视项目的情况，避免用死劲。
