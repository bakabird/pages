**macOS 应用环境变量注入方案总结** 📝

要在 macOS 中为特定 App 设置注入的环境变量，常见方案如下：

1. **修改 `Info.plist`（推荐，支持双击启动）** 💡

- **操作**：右键 App 选“显示包内容”，修改 `Contents/Info.plist`，在根 `<dict>` 下添加 `<key>LSEnvironment</key>` 字典及键值对。
- **注意**：修改后需运行 `lsregister -f` 刷新 LaunchServices 缓存；若导致签名损坏无法启动，需用 `codesign --force --deep --sign -` 重新重签。

2. **Automator / 脚本包装（无侵入替代方案）** 🤖

- 使用 Automator 创建“应用程序”，运行 Shell 脚本：
`export VAR="value" && open -a "YourApp.app"`
- 避开了破坏原 App 代码签名的风险。

3. **终端命令行临时启动** 💻

- 通过 `env VAR="value" open -a "YourApp"` 或直接运行二进制文件启动，仅对当前次有效。

4. **动态库注入（高级/调试）** ⚙️

- 使用 `DYLD_INSERT_LIBRARIES` 运行时注入，受 macOS SIP 及 Hardened Runtime 机制限制。

---

```
<key>LSEnvironment</key>
<dict>
    <key>MY_ENV_VAR</key>
    <string>my_value</string>
    <key>API_KEY</key>
    <string>123456</string>
</dict>
```
