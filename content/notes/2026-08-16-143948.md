## 启动

```
① hub（终端常驻，二选一）
   cd ~/LLMLocalPorxy/hapi
   HAPI_LISTEN_HOST=0.0.0.0 bun run dev:hub   # 开发，热重载
   hapi hub --relay                           # 编译版 + 公网隧道

② runner（手机远程开会话必需）
   hapi runner start
   hapi runner start --workspace-root ~/work  # 限制可开目录

③ 在某目录开会话
   cd /你的项目
   hapi          hapi codex     hapi --yolo    hapi resume
```

## relay（不打断已跑的 hub）

```
cd ~/LLMLocalPorxy/hapi/shared/tools/tunwg
TUNWG_PATH=~/.hapi/tunwg TUNWG_API=relay.hapi.run \
TUNWG_AUTH=$(jq -r .relayAuthKey ~/.hapi/settings.json) \
TUNWG_RELAY=true \
./tunwg-arm64-darwin --json --log_level=0 \
  --forward=http://localhost:38621
→ 日志 {"msg":"listener started","url":"https://…"}
URL 公网可达，只有 token 挡着；不用就 Ctrl-C
```
